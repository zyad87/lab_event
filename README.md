# Lab Event — Expo App

تحويل تمرين `W5-D2-Lab1` من صفحة HTML/JS إلى تطبيق **Expo (React Native)** بنفس الوظائف.

## الوظائف
- **Change content**: يضيف نص جديد للفقرة.
- **Increase / Decrease font size**: يكبّر / يصغّر حجم الخط.
- **Change color**: لون نص عشوائي.
- **Change background**: لون خلفية عشوائي.
- **Change background Image**: يبدّل بين صورتين كخلفية.

## التشغيل

```bash
npm install
npm start
```

ثم:
- امسح الـ QR code بتطبيق **Expo Go** على جوالك، أو
- اضغط `a` لتشغيل محاكي Android، أو `i` لمحاكي iOS، أو `w` للويب.

## الملفات
- `App.js` — الكومبوننت الرئيسي (كل الأزرار والحالة).
- `app.json` — إعدادات Expo.
- `package.json` — الاعتماديات وأوامر التشغيل.
- `babel.config.js` — إعداد Babel لـ Expo.

> الملف الأصلي `index.html` و `min.js` محفوظين في تاريخ Git قبل التحويل.
